# 🛍️ HL Shopping

**HL Shopping** is a modern and responsive fashion e-commerce website designed using **HTML and CSS**. It provides a clean shopping interface where users can explore products, categories, deals, new arrivals, and best sellers.

## ✨ Features

* 🏠 Home page
* 👕 Fashion categories
* 🛍️ 20 product cards
* 🔥 Today's Deals
* 🆕 New Arrivals
* ⭐ Best Sellers
* 🔎 Search bar UI
* ❤️ Wishlist UI
* 🛒 Shopping Cart UI
* 🔐 Login section
* 📧 Newsletter section
* 📞 Contact section
* 📱 Responsive design
* 🎨 Premium and clean user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design

The design focuses on a **simple, premium, and user-friendly shopping experience**.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Make sure the `images` folder contains all product images.
4. Open `index.html` in your browser.
5. The website will be ready to use.

You can also use the **Live Server** extension in VS Code to run the project.
